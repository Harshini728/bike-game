# Bike Game

A lightweight browser-based bike game built with HTML5 Canvas.

## How to run

Open `index.html` in a browser, or serve the project locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Game controls

- Left / Right arrows or A / D: move between lanes
- Up arrow or W: jump
- Space: jump
- R: restart after game over

## Gameplay

- Ride through traffic and avoid obstacles
- Collect coins for bonus points
- Survive as long as possible
- Try to beat your high score

## Project structure

- `index.html` — page structure
- `style.css` — game styling
- `game.js` — game logic and rendering
